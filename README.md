create a new project on Microsoft Visual Studio and paste this code in your main file.
after compiling the code, go to C:/Users/[UserName]/source/repos/[your repository name]/[your console app name]/x64/debug.
then create a shortcut for the executable file.
press win + R and type in shell:startup.
move the shortcut in that folder.
features:
  F1 pauses/plays music.
  F2 goes to the previous.
  F3 goes to the next.
